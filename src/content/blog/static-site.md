## 从需要的功能出发

个人分享网站主要是阅读内容。写作可以发生在编辑器里，版本记录交给 Git，公开页面在构建时生成。

这样一来，网站的主要维护工作就是整理内容与检查链接。

## 内容就是文件

```text
写 Markdown → Git 提交 → 构建静态页面 → 发布
```

每篇内容可以附带标题、日期、标签等元数据。网站根据这些信息生成列表、标签页和订阅源。

## 把复杂度用在值得的地方

对这个网站来说，值得投入的是阅读体验：

1. 在手机上也能舒服地阅读。
2. 代码和表格不会挤坏布局。
3. 内容可以按主题与标签找到。
4. 新增文章时，首页、RSS 和 Sitemap 自动更新。
